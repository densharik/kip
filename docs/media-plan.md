# Медиа-план: видео и скрины для README

Всё, что нужно снять, в порядке приоритета. Внизу - полный список фич с тем,
как каждую показать.

## 0. Подготовка сцены (один раз, до записи)

**Окно и запись**

- Размер окна kip: 1440x900 логических. На retina это 2880x1800 - хватит на
  README (ужмётся до 1400px) и на 1080p видео.
- Запись: QuickTime "New Screen Recording" по окну, либо CleanShot/Shottr.
  30 fps достаточно, курсор показывать.
- Один прогон = один непрерывный дубль. Резать потом.

**Настройки kip перед съёмкой**

- Тема: одна на весь ролик. Tomorrow (дефолт) или One Dark - обе читаемы в GIF.
- Шрифт: Hack 12, масштаб UI 1.2 (дефолты).
- Язык: EN, если ролик для GitHub. RU-версию можно снять вторым дублем.
- `Усыплять после` временно поставить **1 мин** - иначе авто-усыпление не снять.
  Вернуть 10 после съёмки.

**Что должно быть в сайдбаре** (готовим заранее, 6 строк)

| # | Имя               | Директория      | Состояние                    |
|---|-------------------|-----------------|------------------------------|
| 1 | api-refactor      | реальный проект | live, claude работает, 81%   |
| 2 | docs              | другой проект   | live, claude на промпте, 63% |
| 3 | landing           | третий          | live, idle, 34%              |
| 4 | build             | любой           | live, крутится `make`/`sleep`|
| 5 | notes             | ~/notes         | suspended (уже усыплена)     |
| 6 | infra             | любой           | в группе "infra", закреплена |

Сессии 1-3 нужны с разными процентами контекста: это главный кадр всего ролика.
Быстрый способ добить процент - в тестовом проекте попросить claude прочитать
несколько крупных файлов.

**Гигиена**

- Пути в чипе снизу показываются как `~/...` - но имена проектов видны. Если в
  них что-то личное, переименуй сессии двойным кликом (custom name перебивает
  claude_title).
- В терминале не должно висеть чужих токенов, `.env`, приватных путей.
- Панель лимитов Claude показывает реальный процент подписки - это нормально,
  но если не хочешь светить - открути на аккаунте, где проценты низкие.

## 1. Главный ролик (hero в README, ~80 секунд, без звука)

Один непрерывный сюжет: "запускаю пять агентов, вижу кто где, гашу лишние,
закрываю приложение, открываю - всё на месте".

| Тайм  | Что в кадре | Что делать |
|-------|-------------|------------|
| 0:00-0:05 | Окно целиком: сайдбар с 6 сессиями, справа терминал активной | Ничего. Просто дать разглядеть. Бейджи 81% / 63% / 34% сразу видны, 81% пульсирует |
| 0:05-0:12 | Сайдбар крупно (можно zoom в монтаже) | Медленно провести курсором сверху вниз по списку. Видны: точка статуса, имя, путь, бейдж % |
| 0:12-0:20 | Клик по сессии 1, потом 2, потом 3 | Показать, что терминал мгновенно переключается и скроллбэк на месте. Можно через Cmd+1, Cmd+2, Cmd+3 - но тогда наложить титр с шорткатом |
| 0:20-0:30 | Панель ресурсов | Навести на чип с барами в правом верхнем углу. Панель раскрывается: строка `kip` серая сверху, под ней каждая живая сессия с RAM и % cpu, снизу `total`. Задержать 4-5 сек, дать цифрам обновиться (тик 2 сек) |
| 0:30-0:42 | Усыпление | Правый клик по сессии 3 -> `Suspend`. В терминале появляется карточка "Session suspended / processes stopped, memory freed" с кнопками. Точка в сайдбаре становится полым кружком. **Сразу навести на панель ресурсов** - строки этой сессии больше нет, total упал. Это ключевой кадр всего ролика |
| 0:42-0:50 | Возврат | Клик `Resume Claude` на карточке. Терминал заполняется старым скроллбэком, снизу подставляется `claude --resume <id>`, бейдж % появляется до того, как claude загрузился |
| 0:50-0:58 | Авто-усыпление | Титр "idle for 1 minute". Сессия 3 (не трогали) сама гаснет: точка -> полый кружок, карточка suspended. Сессия 4 с работающим `make` при этом **не гаснет** - показать её точку зелёной. Это отдельный смысл: усыпляется простой, а не работа |
| 0:58-1:06 | Закрепление | Попробовать потащить закреплённую сессию 6 - булавка качается, строка не двигается. Навести на булавку: тултип "Pin: no close, no drag, no auto-suspend" |
| 1:06-1:14 | Лимиты Claude | Навести на чип в правом нижнем углу. Всплывает список: Session 5h / Week / Week: Fable с процентами и "resets in 2h 14m". Нажать булавку на строке `Session 5h` - панель закрывается, в углу остаётся полоска `5h ███░░ 47%` |
| 1:14-1:22 | Выход и возврат | Cmd+Q. Пауза 1 сек на пустом рабочем столе. Запустить kip заново - те же 6 сессий, те же имена, группы, закрепление, у каждой сохранён экран. Клик `Resume Claude` на первой - продолжает тот же разговор |

Титры: только шорткаты и три смысловых (`idle for 1 minute`, `quit`, `relaunch`).
Никаких голосовых пояснений - ролик должен читаться без звука в README.

**Экспорт:** mp4 1920x1080 в релиз/issue (GitHub принимает drag&drop mp4 в
README через ссылку на user-content), плюс GIF 1400px шириной, до 8 МБ, для
инлайна. Если GIF не влезает - режь на два: "sessions + context %" и
"suspend + resume".

## 4. Полный список фич и как показать каждую

Сгруппировано. То, что уже покрыто главным роликом или клипом, помечено.

### Сессии

1. **Сайдбар: имя, путь, статус-точка.** Точка: зелёная = процесс работает,
   серая = живой шелл на промпте, полый кружок = усыплена, красная = процесс
   вышел с ошибкой. Показывать: кадр сайдбара, где есть все четыре. *(hero, sidebar.png)*
2. **Контекст % на каждой сессии.** Зелёный до 50, жёлтый 50-70, красный и
   пульсирует выше 70. Появляется сразу после resume, до загрузки claude.
   *(context.gif)*
3. **Закрепление сессии.** Не закрывается, не перетаскивается, не усыпляется
   автоматически. При попытке тащить булавка качается. *(pin.gif)*
4. **Группы.** Создаются перетаскиванием одной сессии на другую, заголовок
   цветной, члены с отступом, сворачиваются, порядок меняется драгом,
   переживают перезапуск. *(groups.gif)*
5. **Переименование двойным кликом.** Своё имя перебивает то, что придумал
   claude. Снять: двойной клик, поле с выделенным текстом, ввод, Enter.
6. **Cmd+1..9** - прыжок на сессию по номеру. Закреплённая держит свой номер,
   даже если список перетасовали. Снять с титром-шорткатом.
7. **Ресайз панели.** Тянуть за правый край: длинные имена перестают
   обрезаться. *(resize.gif)*

### Память и жизненный цикл - главное в проекте

8. **Ручное усыпление.** Дерево процессов убивается по-настоящему (SIGKILL по
   всему дереву), экран сохраняется текстом. Снимать **обязательно с открытой
   панелью ресурсов**, иначе не видно смысла. *(suspend.gif)*
9. **Авто-усыпление по простою.** Настройка в минутах, 0 = выключено, дефолт 10.
   Ключевая деталь для кадра: claude, висящий на своём промпте, считается
   простоем, а работающий `make`/`rsync` - нет. Снять обе сессии в одном кадре.
   *(autosuspend.gif)*
10. **Keep awake.** Правый клик -> `Keep awake`, справа в строке появляется `!`.
    Такая сессия не гаснет никогда.
11. **Возврат.** `Resume Claude` подставляет `claude --resume <id>` и
    восстанавливает экран. `Continue in terminal` поднимает голый шелл в той же
    папке. Снять обе кнопки. *(hero)*
12. **Переживание выхода из приложения.** Cmd+Q -> запуск -> все сессии на
    месте, у каждой сохранён последний экран (32 КБ) и id разговора claude.
    Ничего не надо нажимать заранее. *(hero, финал)*

### Мониторинг

13. **Панель ресурсов.** RAM и CPU по каждой живой сессии (вся ветка процессов)
    плюс сам kip отдельной строкой, снизу total. Обновляется раз в 2 секунды и
    только пока открыта. *(resources.png)*
14. **Лимиты подписки Claude.** Session 5h, Week, Week по модели - те же цифры,
    что показывает `/usage` внутри claude. Любую строку можно закрепить, и её
    полоска останется в углу навсегда. *(usage.gif)*
15. **Git внизу.** `+42 -7`, `clean`, `not git` для папки активной сессии.
    Снять: сделать правку в файле, увидеть, как цифры выросли.
16. **Уведомления.** Системное уведомление, когда агент закончил работу (с
    длительностью), и по bell из терминала. Снять: свернуть kip, дать claude
    длинную задачу, поймать баннер macOS в кадр.

### Терминал (важно показать, что это терминал, а не обёртка)

17. **Это настоящий PTY.** Отдельный короткий кадр: в сессии запускается `htop`,
    потом `vim`, потом `ssh` куда-нибудь. Всё рисуется. Это доказательство
    тезиса "терминал, а не приложение-клиент".
18. **Кликабельные пути в выводе.** Клик по пути -> Open / Reveal in Finder.
    *(paths.gif)*
19. **Drag & drop файла** в строку ввода -> вставляется путь. *(dnd.gif)*
20. **Вставка картинки из буфера** (Cmd+Shift+4, потом Cmd+V) -> вставляется
    путь к png, claude его читает. *(dnd.gif)*
21. **Shift+Enter** - перенос строки в командной строке, без отправки.
22. **История команд** - стрелка вверх на пустой строке даёт последнюю команду,
    список открывается кнопкой History.
23. **Копирование по выделению** - выделил мышью, уже в буфере (настройка).
24. **Мышь в приложениях** с mouse tracking - колесо прокручивает внутри
    `less`/`htop`, а не скроллбэк.

### Файлы и навигация

25. **Переключатель директорий** - клик по чипу пути внизу, поиск подпапок,
    создание папки прямо в попапе, `cd` уезжает в терминал. *(dirswitch.gif)*
26. **Панель файлов** - между сайдбаром и терминалом, обзор, поиск по имени,
    новый файл, новая папка. *(explorer.gif)*
27. **Finder Services** - правый клик по папке в Finder -> "New kip Window Here".
    Снять прямо в Finder, это хорошо продаёт интеграцию.

### Оформление

28. **6 тем + акцент выделения.** *(themes.gif, themes.png)*
29. **9 шрифтов терминала**, размер, масштаб UI (Cmd+= / Cmd+- / Cmd+0). Снять
    перебор шрифтов на одном и том же выводе.
30. **Русский и английский**, переключается на лету без перезапуска.

### Прочее

31. **Самообновление** из настроек, проверка дважды в день. *(update.gif)*
32. **skip-permissions по умолчанию** для новых сессий - тумблер в настройках.
33. **Statusline-хук** для точного процента: ставит скрипт в `~/.kip/bin` и
    прописывает его в `~/.claude/settings.json`. Снять: включить тумблер и
    показать, как процент начинает обновляться раз в секунду вместо оценки.
