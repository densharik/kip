# Security

Report a vulnerability privately through GitHub:
[Security > Report a vulnerability](https://github.com/densharik/kip/security/advisories/new).
Please do not open a public issue for it.

Only the latest release is supported; kip updates itself, so fixes ship as a
new release. Releases are signed, and the in-app updater installs only an
update whose ed25519 signature checks out.
